# arda-rumil ownership

## Rúmil owns

- bounded project audit coordination and project identity
- inventory/adaptor/provider evidence normalization
- command receipts, normalized findings, selected baselines, and comparisons
- review-only organization plans and audit-owned packet retention

## Rúmil does not own

- **Vairë (`arda-vaire`)** — durable episodic/semantic/procedural memory and eligibility policy. Rúmil supplies only bounded receipt metadata and summaries.
- **Warden / `arda-outpost-scout`** — public research, outpost observation, and follow-up research questions. The scout may request Rúmil evidence but does not absorb its implementation.
- **Mandos (`arda-mandos`)** — advisory reasoning and evidence-linked verdicts. Mandos consumes references without gaining filesystem authority.
- **Varda (`arda-varda`)** — governed evaluation/executor boundaries. Rúmil findings never authorize execution.
- **Arda Engine** — harness and product projection surfaces. It may project packet state but does not become the audit authority.
- **Cargo, Git, cargo-audit, cargo-deny, cargo-modules, syntax providers** — source analysis logic. Rúmil registers, bounds, and receipts these tools instead of reimplementing them.

## Mutation boundary

Rúmil has no delete, move, archive, rewrite, or arbitrary-shell authority. Any future mutation handoff must use a separate operator/governance contract with explicit path-and-evidence approval.
