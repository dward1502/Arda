- 2026-08-13 — HUD production dependency findings resolved by upgrading
  `mermaid` from `11.16.0` to patched `11.16.1`, which also advanced
  `dompurify` from `3.4.12` to patched `3.4.13`. `pnpm audit --prod --json`
  reports 0 low, moderate, high, or critical findings across 201 production
  dependencies. `pnpm test -- mermaidCanvasRenderer` passed the configured full
  suite (131 files, 518 tests), `pnpm lint` exited zero with the existing warning
  backlog, and `pnpm build` passed.
- 2026-08-14 — Repository-wide HADES validation checked 423 local Markdown
  links with 0 broken links and 0 active-plan completion-language issues. The
  repair removed 34 deleted entries from the generated `core/state` inventory,
  repaired two stale `core/knowledge/clients` paths, and taught the validator to
  preserve vendored Rust intra-doc links; its focused suite passed 5/5.
- 2026-08-14 — A current-source native HUD baseline was recorded in
  [`hud-native-performance-accessibility-baseline-20260814.json`](../evidence/0.9/hud-native-performance-accessibility-baseline-20260814.json).
  The source-built binary passed compilation and all 518 frontend tests, but the
  hardware-backed X11 path rendered a black webview after a GBM allocation
  failure. The DMABUF-disabled rendering fallback peaked at 647.17 MiB aggregate
  RSS and 106.05% of one CPU core during a 60-second sample, and native WebKit
  exposed no HUD content semantics. This closes baseline recording, not native
  qualification; the defect-triage/rebuild item remains open and fail-closed.
- 2026-08-14 — Native remediation now makes the launcher prefer the compositor's
  Wayland socket instead of the repeatedly failing NVIDIA/X11 GBM path. The
  explicit DMABUF-disabled compatibility profile preserves the complete static
  boardroom while reducing measured CPU from 106.05% to 12.51% and 12.59% of one
  core across two one-minute samples. Native AT-SPI now exposes 36 named
  boardroom controls; its Settings action was invoked successfully and exposed
  the Settings surface plus Close Settings control. The normal animated Wayland
  path measured 38.90% of one core and 665.87 MiB peak aggregate RSS, while the
  compatibility path reached 610.01 MiB in its second minute. Renderer routing,
  fallback CPU, and semantic-control defects are repaired, but the historical
  memory/animated-idle budgets and complete keyboard/screen-reader acceptance
  remain open before artifact rebuild.
- 2026-08-14 — Native qualification replaced the misleading aggregate-RSS-only
  gate with a host-qualified ownership contract: at 1920×1080, the
  hardware-backed Wayland HUD must remain at or below 40% of one CPU core,
  550 MiB peak aggregate PSS, 16 MiB aggregate PSS growth, and a 700 MiB
  aggregate RSS observability ceiling over five minutes. The isolated
  300.052-second run passed at 33.48% CPU, 533.69 MiB peak PSS,
  -4.77 MiB PSS growth, and 673.34 MiB peak RSS with zero swap. The launcher
  and WebKit network process remained flat; the WebKit content process owned
  a transient roughly 75 MiB allocation/collection sawtooth and ended below
  its starting ownership, so no leak was observed. A tested 30 FPS scheduler
  did not improve CPU and was reverted. The reusable measurement authority is
  `scripts/profile_arda_hud_native.py`.

  presented `Open settings button`, `Settings workstation dialog`, and the
