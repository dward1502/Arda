Composition root

The root arda binary discovers the repository, validates services.toml, starts the engine harness and supervisor, and coordinates shutdown. It is a composition boundary, not a second runtime.

Authority invariant

Interfaces project state; workers perform bounded roles; models contribute evidence. None may mint a second queue, memory, policy, identity, or receipt authority.

Current topology

The live Rust workspace resolves 18 packages. The canonical 0.9 profile is single-operator and loopback-only; remote and multi-user use are unsupported.
