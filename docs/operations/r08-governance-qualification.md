## Redaction repair

A regression demonstrated that Varda copied source text into both governance log
surfaces. The new `record_bacon_lite_to_with_description` adapter scores the full
original task but persists a safe description. Varda uses this adapter for its
governance events. Source ID, policy/version, decision, confidence and rationale
remain available and correlated. The regression compares the retained judgment
to scoring the original task. This is source-description minimization, not a
claim that every caller-controlled context field or all historical logs are
sanitized. No historical source data was rewritten.
