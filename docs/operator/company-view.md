# Company View

This document is the readable business framing for Annunimas.

## What Annunimas Is Building

Annunimas is a sovereign AI operating system for business and personal command.

The end goal is not just a collection of agent crates.  
The end goal is one coherent executive environment where:

- the human principal can operate through ARDA_HUD
- Arandur orchestrates decisions and system posture
- WARDEN secures the network and edge boundary
- the other systems perform specialized work
- the whole stack stays auditable through Triad, Bacon-lite, JouleWork, Love Equation, and Soterion

## Business Direction

The system is being shaped so it can later be:

- used internally for real operations
- separated into cleaner product surfaces
- potentially marketed, sold, or open-sourced in parts

That is why the architecture is being pushed toward:

- router-agnostic interfaces
- clean subsystem contracts
- central configuration and settings
- strong observability and auditability
- readable human and machine layers

## Current Product Shape

Current backend foundation:

- sovereign startup and restart reconciliation
- shared `/core/state` projections
- subsystem runtime parity
- package and storage observation
- human/business/personal projections
- machine primary entrypoint for ARDA: `core/state/arda_snapshot.json`

Current frontend direction:

- ARDA_HUD becomes the main command center
- boardroom UI for executive interaction
- 3D world view for live system posture
- settings/control surfaces backed by `/core/state`

## Near-Term Focus

Before the full ARDA pass, the remaining business-facing work is:

- enrich human-readable business and personal context
- tighten settings semantics
- keep dependency observation current
- continue cleanup and optimization so the system is easier to package and operate

## Principle

Optimization, efficiency, and beautiful interaction are the target.

The backend should make that possible.  
ARDA_HUD should make it natural.
