Use it to record:
- explicit operator intent that should supersede ambient automation
- temporary sovereign directives
- exceptional human judgments that need to be legible later

Do not use it for:
- rough notes
- normal planning chatter
- machine-generated state

Readable realm contract:
- `docs/operator/overrides.md` for explicit human intervention
- `docs/operator/philosophy.md` for canonical readable philosophy/thought path
