# Core Arda Usefulness Repair

## Product promise

An operator can speak or type through Hermes or the HUD, and Arda will:

1. recognize a capture, question, context request, or consequential request;
2. save it under the correct durable authority;
3. return one trustworthy next action or source-grounded answer;
4. request exact review where authority requires it;
5. expose execution and receipts;
6. survive restart and restore the same context through Hermes/HUD.

This plan owns composition and usefulness. Domain contracts remain owned by their existing crates and services. It must not create another queue, memory store, research authority, policy system, or runtime.

## Holds

Until the operator accepts the core journey:

- Mirromere remains stopped;
- no RELIC expansion, sensors, physical outposts, or commercialization execution;
- no external agent account, Moltbook account, wallet, funded account, trade, payment, or public posting;
- economic and agent-community objectives remain reviewed research/planning only.
