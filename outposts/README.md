# Outposts

Arda outpost crates live here. These are standalone Rust crates built for Pi5/runtime
deployment with scoped public surfaces.

Current crates:
- `arda-outpost-protocol` — shared observation contract/schema
- `arda-outpost-scout` — repo survey/observation tooling for Warden evidence nodes

Each crate contains its own README with API usage, test commands, and maturity notes.
